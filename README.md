# Premium Butcher — Boutique App

> Interactive app prototype for premium butcher shops, featuring curated cuts, barbecue content and in-store pickup.

`HTML5` · `CSS3` · `JavaScript` · `Tailwind CSS (CDN)`

## 🇬🇧 English

**Segment:** Premium butchery & barbecue

Interactive app prototype for premium butcher shops, featuring curated cuts, barbecue content and in-store pickup.

**Highlights**

- Curated premium cuts and a weekly featured selection
- Grill school with step-by-step preparation guides
- Delivery and in-store pickup options

**Tech:** HTML5, CSS3, vanilla JavaScript, Tailwind CSS via CDN.

**Run it:** Open `index.html` in any modern browser — no build step, no dependencies to install.

_This is a design prototype: data is mocked in the front-end and there is no back-end._
